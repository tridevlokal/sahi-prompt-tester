# AI Riya — voice agent tester

Realtime voice tutor demo: Gemini LLM + Google Chirp3-HD / ElevenLabs TTS + Sarvam / Google STT.
Open the Space, pick a language and voice, press **Call**, and talk.

Runs as a FastAPI + Pipecat WebSocket server (see `server.py`, `bot.py`).
